# Inheritance decision dashboard

A privacy-first static dashboard for reviewing inheritance decisions, with official-source links, an uncertainty register, and a 50-year illustrative stress test. The site is built using only Python's standard library.

```sh
python3 tools/build.py
python3 tools/verify.py
```

GitHub Pages is configured to build from the root of `main`. Jekyll's `_config.yml` excludes the board and tooling from the site. Do not add case-specific financial information to this public repository. The public site contains no case-specific financial inputs or derivative dollar estimates. Rounding is not a guarantee of anonymity. The repository and its history are public: deleting files in a subsequent commit does not erase previous commits, deployments, caches, or forks. See the task board for the privacy incident and outstanding remediation.

The dashboard is educational, not legal, tax, investment or insurance advice. Unconfirmed case-specific values are intentionally blank. Models are hypothetical, not official predictions or personalized recommendations.
