Privacy and limitations

Privacy is the first release gate: case figures appear only rounded to $10 with no addresses or identifiers, and public Git history still needs owner/admin review.

Privacy warning — history is not fully scrubbed

The repository is public. The current branch tree publishes only $10-rounded case figures with no identifiers, but historical Git objects, earlier public PRs, forks, caches and clones may retain unrounded or more detailed case-derived material. This branch cannot rewrite public main history; repository-owner/admin coordination is required. Treat prior values as exposed.

The generated pages use local HTML, CSS and JavaScript only. They contain no analytics, remote fonts, remote scripts, API calls or form submissions. External official sources open only when a reader follows a link.
