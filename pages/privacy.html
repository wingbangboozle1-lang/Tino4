Privacy and limitations

Privacy is the first release gate. No household-specific values or locations are published in the current site, but public history still needs owner/admin review.

Privacy warning — history is not fully scrubbed

The repository is public. The current branch tree publishes only rounded figures, but historical Git objects, earlier public PRs, forks, caches and clones retain earlier, unrounded case material (the flagged page records the pattern-audit counts). This branch cannot rewrite public main history; repository-owner/admin coordination is required. Treat prior values as exposed regardless of the current site's rounding.

No third-party tracking

The generated pages use local HTML, CSS and JavaScript only. They contain no analytics, remote fonts, remote scripts, API calls or form submissions. External official sources open only when a reader follows a link.

Planning framework only. Not legal, tax, insurance, appraisal or investment advice. A source supports only its stated scope, not a private fact. Owner-supplied figures are privacy-rounded to the nearest $10 at the owner's direction and flagged; blanks mean unknown, not zero.
