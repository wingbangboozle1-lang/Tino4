Privacy and limitations

Privacy is the first release gate. No household-specific values or locations are published in the current site, but public history still needs owner/admin review.

Privacy warning — copies outside the repository

The repository is public. The current tree and the published branch history are free of case-derived material, but pull-request diffs, forks, cached views and clones may still hold earlier copies. Nothing published here should be treated as a substitute for repository-owner coordination.

No third-party tracking

The generated pages use local HTML, CSS and JavaScript only. They contain no analytics, remote fonts, remote scripts, API calls or form submissions. External official sources open only when a reader follows a link.

Planning framework only. Not legal, tax, insurance, appraisal or investment advice. A source supports only its stated scope, not a private fact. Blank means unknown, not zero. The public site intentionally contains no property-specific dollar values or locations.
