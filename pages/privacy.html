Privacy & publication

Rounded case figures, labeled assumptions and verified rules — separated clearly so nothing reads as a promise.

Highest priority: anonymized publication, rounded figures

This is a public static site in a public Git repository. The owner directed that costs and numbers be used but rounded to the nearest $10 so they cannot be traced back to the source; identities are replaced with placeholders. Noindex is a search preference, not confidentiality.

Status labels: Verified = official statement read directly; Owner-supplied = figure from the owner, rounded to $10, not independently confirmed; Projection / Assumption = model output of labeled assumptions; Guidance = analysis; Missing = deliberately blank, never zero; Synthetic = invented illustration.
