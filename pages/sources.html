Every source used on this site with its scope and check date, so any claim can be reviewed manually.

How to read this register

Every table row on this site links to one of these sources, and every link opens the official page. A source supports only its stated scope — it never validates a private property fact. Damodaran's historical-return compilation and CBO's rate outlook are flagged secondary: reputable, but not primary market data.
