Black-swan conditions

Rounded case figures, labeled assumptions and verified rules — separated clearly so nothing reads as a promise.

Growth and inflation are never consistent for 50 years

A smooth 3%/yr line is a spreadsheet convenience. This page uses real, officially documented episodes to show what jagged looks like — and how each path absorbs it. None of these episodes is a forecast; a true black swan is by definition outside this list.
