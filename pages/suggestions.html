S1Put a break-even rent figure beside the occupancy comparisonTurns the largest single unknown into one number that written comparables can settle, instead of a fifty-year projection.Low: one page, already drafted as the break-even page.GuidanceHUD — Fair Market Rents · IRS Publication 527 — Residential Rental Property
S2Show every headline twice, nominal and in today's dollarsA nominal fifty-year figure is roughly three times its real value at 2.5 percent inflation, which makes paths look far more generous than they are.Low: one extra column in each model output.GuidanceU.S. Bureau of Labor Statistics — CPI
S3Mark a path unauthorised, not estimated, when an input is missingStops a confident ranking from appearing when one path's key input is absent, which is the most common way a planning model misleads.Low: a status field per path.GuidanceIRS — Gifts and inheritances FAQ · California Department of Insurance — Residential insurance
S4Add a distribution chart of terminal outcomes across orderingsA single line hides that the same average return in a different order produces a different result when money moves in and out.Medium: run the same assumptions in several orderings and plot the spread.GuidanceSEC Investor.gov — Stocks · Congressional Budget Office — Long-Term Budget Outlook
S5Publish a five-year capital plan with bid placeholders for both buildingsConverts maintenance from a percentage of value into dated line items, which is what actually forces a sale in a bad year.Medium: an inspection and two bids per line item.GuidanceCalifornia Contractors State License Board — Check a license · IRS Publication 527 — Residential Rental Property
S6Separate the three tax ledgers explicitly on every pageEstate-tax value, income-tax basis and assessed value answer different questions and are routinely conflated; keeping them apart prevents a wrong threshold being applied to the wrong number.Low: already partly done; make it a fixed panel.GuidanceIRS — Estate tax · IRS — Gifts and inheritances FAQ · California Revenue and Taxation Code §51

S8Model the same-year sale before any other sell variantThe transfer-year sale is the case with the least time for facts to change, so it is the natural benchmark against which every delay must justify itself.Low: an ordering rule in the model.GuidanceIRS — Gifts and inheritances FAQ · California statute — documentary transfer tax

What adopting one of these is not

Adopting a presentation change is not a decision about the estate. A clearer site makes the missing facts obvious; it cannot supply them. No suggestion on this page should be read as an instruction to sell, rent, occupy or retain any property.
