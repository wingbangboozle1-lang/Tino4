## Rules (restated so they survive a fresh session)

1. Claim a task by writing your session ID + file scope below, then **commit and push the
   claim immediately**.
2. Never start a task another session has claimed and is actively working.
3. Keep scopes non-overlapping. Each session works only on its own branch, named
   `session-<id>/<task>`, and edits only files inside its claimed scope.
4. If a task requires changing a file owned by another session, log the request here
   instead of editing the file.
5. Small, frequent commits. `git pull --rebase` before every push. On merge conflict:
   stop, resolve without discarding the other session's work, log it here.
6. A claim older than 60 minutes with no commits may be taken over; note the handoff.
7. `needs review` = published on the site's **Flagged for Review** page; it does not block
   anything.
8. Shared outputs — `data/`, `site/index.html`, `site/assets/nav.js`, the final HTML pages —
   are written only by the **integration** task once the research tasks are done.
9. Never mark something verified without checking it against an official source and linking it.
