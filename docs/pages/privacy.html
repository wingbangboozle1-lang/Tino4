How the public site is isolated

GitHub Pages publishes only the docs/ directory. Internal working notes live in internal/ and are not part of the published site. Those internal notes also contain no personal information. User-supplied figures appear only as clearly labelled unverified model inputs; the raw request text is never published.

Verification

A privacy scan runs as part of tools/verify.py, checking the published HTML for names, addresses, parcel numbers, phone numbers, email addresses and the literal cash-amount marker. See the Source Register and Flagged for Review pages for manual review.

Computed costs, projections and all decision figures are rounded to the nearest $10; statutory amounts are quoted exactly as published at the linked official source. Verified facts are marked VERIFIED; computed outputs are marked MODEL; unconfirmed values are left blank and marked UNVERIFIED.
